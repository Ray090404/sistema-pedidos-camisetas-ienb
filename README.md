# Sistema de Pedidos de Camisetas — IENB

Sistema web desenvolvido para facilitar o cadastro e o gerenciamento de pedidos de camisetas do **Congresso Gênesis & Maraata 2026**.

O projeto foi criado para atender a uma necessidade real, tornando a coleta de tamanhos e modelos mais organizada e facilitando o acompanhamento dos pedidos.

## Funcionalidades

- Cadastro de pedidos com nome completo.
- Seleção de modelo e tamanho da camiseta.
- Armazenamento dos pedidos no banco de dados.
- Integração com Supabase.
- Interface responsiva e identidade visual personalizada.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- Vercel

## Objetivo do projeto

Aplicar conhecimentos de desenvolvimento web na construção de uma solução prática, desde a criação da interface até a integração com banco de dados e a publicação da aplicação.
